# MERN Job Portal

A full stack Job Portal web application built using the **MERN Stack**.

## 🚀 Tech Stack

Frontend

* React.js
* Redux Toolkit
* Tailwind CSS
* Vite

Backend

* Node.js
* Express.js
* MongoDB

Other Tools

* JWT Authentication
* Cloudinary (image upload)

---

## ✨ Features

### Job Seekers

* Signup / Login
* Browse jobs
* Apply to jobs
* Update profile
* Upload resume

### Recruiters

* Create company
* Post jobs
* Manage job listings
* View applicants

## ⚙️ Installation

Clone the repository

```
git clone https://github.com/know-vikas/jobportal.git
```

Install backend dependencies

```
cd backend
npm install
```

Install frontend dependencies

```
cd ../frontend
npm install
```

Run backend

```
npm run dev
```

Run frontend

```
npm run dev
```
